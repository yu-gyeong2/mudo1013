# 🏃 무한도전 텔레파시 레이스 (8인 동기화 웹앱)

진행자 없이 **8명 전원이 평등한 플레이어로 참여**할 수 있는 양재천 텔레파시 레이스 모바일 웹앱입니다.

---

## 📱 핵심 기능

1. **시간 기반 자동 동기화 (Absolute Clock Sync)**
   - 방장이나 참가자가 시작 시각(예: 14:00)을 설정하고 **QR 코드** 또는 **링크**를 공유하면, 8명의 스마트폰이 **1초의 오차 없이 동일한 카운트다운 타이머**를 공유합니다.
   - 현장에서 데이터 연결이 불안정해도 한 번 로딩된 후에는 로컬 시계 기반으로 정확히 동작합니다.

2. **스마트폰 봉인 모드 (주머니 모드)**
   - 미션 확인 후 "봉인하기"를 누르면 검은색 절전 화면으로 전환되며 주머니에 넣고 양재천을 누빌 수 있습니다.
   - 연락(카톡/전화/지도) 금지 수칙 안내와 함께, 정각 타임오버 시 **자동 알람 부저음(Web Audio) 및 스마트폰 진동**으로 상봉 시각을 알려줍니다.
   - 주머니 속 오작동을 방지하는 3회 탭 해제 안전장치가 적용되어 있습니다.

3. **무한도전 미션 카드 봉투 열기**
   - 시작 시각에 봉투를 터치하면 긴장감 넘치는 효과음과 함께 봉투가 개봉되며 라운드별 힌트가 무한도전 자막 스타일로 나타납니다.
   - 후보 스팟 토글 기능으로 길을 헤맬 때 힌트 장소를 슬쩍 확인할 수 있습니다.

4. **상봉 인증샷 & 무한도전 자막 워터마크**
   - 상봉 시 스마트폰 카메라로 무한도전 포즈 셀카를 촬영하면 하단에 **"무한도전 엠블럼 + 2026.10.12 양재천 상봉 성공!"** 자막이 자동 합성됩니다.
   - 혼자 남았을 때도 고독한 인증샷을 남길 수 있습니다.

5. **자동 점수 계산기 & 뒷풀이 최종 정산**
   - 함께 만난 멤버들을 터치하면 **(인원 수 × 10점)** 자동 계산!
   - 혼자 남은 멤버는 **0점 및 해골(💀) 효과음**!
   - 8명 전원 합체 시 **폭죽(Confetti) 팡파르와 회비 전액 면제 잭팟**!
   - 뒷풀이 장소에서 1위~8위 랭킹, **텔레파시 최강 콤비 상**, **외로운 늑대상(프로 고독러 벌칙)**을 발표하고 카톡으로 복사할 수 있습니다.

6. **커스텀 라운드 & 8인 멤버 설정**
   - 기본 제공되는 양재천 3라운드 코스 외에도 멤버 8명의 실제 이름, 힌트 내용, 후보 스팟을 자유롭게 수정할 수 있습니다.
   - 한강 피크닉, 대학 캠퍼스 추억 코스 프리셋도 함께 탑재되어 있습니다.
   - 1분 단위 초고속 데모 모드로 사전에 전체 흐름을 테스트해볼 수 있습니다.

## 🚀 로컬 실행 방법

```bash
cd C:\Users\User\.gemini\antigravity\scratch\muhan-telepathy
npm run dev -- --host
```

브라우저에서 `http://localhost:5173` 접속 또는 스마트폰으로 같은 와이파이 / 핫스팟의 IP 주소로 접속할 수 있습니다.
배포 시에는 `npm run build` 후 생성되는 `dist/` 폴더를 Vercel, Netlify, GitHub Pages 등에 정적 웹 호스팅으로 1분 만에 배포할 수 있습니다.
